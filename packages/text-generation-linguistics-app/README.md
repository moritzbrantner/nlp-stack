# text-generation-linguistics-app

React, TypeScript, TailwindCSS, Bun, and oxfmt frontend for `text-generation-linguistics`.

Run the server:

```bash
cargo run -p text-generation-linguistics-server -- --addr 127.0.0.1:3000
```

Run the app:

```bash
bun run --cwd packages/text-generation-linguistics-app dev
```
